# Distinct style selection

Pick a visual language before choosing effects. Color registers are intentionally labelled.

- `dark-academia` — Visual style / `scholar-folio`: Gothic library, double rules, manuscript drop cap, marginal notes; not a brown product grid.
- `cyberpunk` — Visual style / `signal-console`: Chamfered controls, rain-lit city, dense telemetry and compressed mono labels; not a neon product page.
- `high-fashion` — Visual style / `atelier-spread`: Monumental Didone, dominant portrait, asymmetry, tiny folios and a boxless look index; not a jewellery dashboard.
- `nordic` — Visual style / `nordic-catalog`: Useful horizontal catalogue, pale timber, layered lamp and quiet typography; not just the Nord terminal palette.
- `bauhaus` — Visual style / `geometric-poster`: Asymmetric modular poster, functional oversized numerals and balanced geometric masses; distinct from decorative Memphis.
- `art-nouveau` — Visual style / `botanical-plate`: Whiplash stems extend into a continuous organic frame; distinct from angular stepped Art Deco.
- `frutiger-aero` — Visual style / `overlap-gallery`: Wet glass, aqua spheres, sky/grass ecology and buoyant layered surfaces.
- `vaporwave` — Visual style / `canvas-hero`: A central retro object, checker horizon and spaced display type; leisure and nostalgia rather than cyberpunk telemetry.
- `mono` — Visual style / `app-panels`: Raw index, heavy rules, block typography, square controls and zero motion.
- `golden-archive` — Visual style / `story-rail`: Pinned artifacts, museum plaques, gold discipline and a chapter rail; scholarship becomes an exhibit rather than a reading room.
- `avant-basic` — Visual style / `overlap-gallery`: Oversized squiggles, checkerboard, flat clashing blocks and hard offsets; a contemporary Memphis-influenced interpretation.
- `organic-tech` — Visual style / `overlap-gallery`: Biomorphic contours, asymmetric rounded fields and botanical interfaces; distinct from Nordic object functionalism.
- `skate-culture` — Visual style / `editorial-split`: Condensed shouting type, torn print edges, rotated stickers and an abrasive zine index.
- `mosaic` — Visual style / `fluid-magazine`: Fragmented tile rhythm, irregular coloured chips and grout-like divisions; no glass or fluid gradients.
- `art-deco` — Visual style / `canvas-hero`: Stepped portals, axial symmetry, fan geometry and tall lettering; distinct from botanical Art Nouveau.
- `frutiger-metro` — Visual style / `overlap-gallery`: Flat flower bursts, dot clusters, swooshes and vivid civic colour; no Aero glass.
- `preppy-2000s` — Visual style / `product-bento`: Argyle panels, varsity slab, crest and ribbon hierarchy; brighter and more commercial than Dark Academia.
- `y2k-chrome` — Visual style / `product-focus`: Liquid-metal hero, stretched glossy controls and lens-flare accents; distinct from vaporwave nostalgia.
- `swiss-international` — Visual style / `fluid-magazine`: Flush-left asymmetric grid, enormous functional numerals and one signal red; no centred hero or decorative frame.
- `editorial` — Visual style / `editorial-split`: Magazine hierarchy, narrow reading columns, rules and numbered stories; less theatrical than High Fashion.
- `neutral` — System / color register / `product-bento`: A functional base system; choose for utility, not as a distinct historical style.
- `hi-contrast` — System / color register / `app-panels`: An accessibility-oriented register with strong contrast and targets; not a historical design movement.
- `pastel` — System / color register / `product-bento`: A soft colour/material register; combine with a deliberate layout rather than calling colour a complete style.
- `earthy` — System / color register / `product-focus`: An earthy craft register; material texture and grounded product staging distinguish it from a beige recolour.
- `jewel` — System / color register / `product-focus`: A deep luxury colour register; choose High Fashion or Art Deco when a stronger compositional language is needed.
- `ultraviolet` — System / color register / `product-bento`: A luminous technology colour register; retain it for products that already own this identity.
- `ember` — System / color register / `app-panels`: A warm-dark tool register; colour temperature is its distinction, not a separate design movement.
